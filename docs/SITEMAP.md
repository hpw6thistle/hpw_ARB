## 主管可用的三條操作路徑

- 各館：登入所屬館別 -> 建立各館草稿 -> 編列房晚與房價 -> 看年度比較 -> 儲存檢查 -> 提交。
- 聯訂：登入聯訂工作 -> 選授權館別 -> 建立聯訂草稿 -> 編列房晚與房價 -> 看年度比較 -> 儲存檢查 -> 提交。
- 財務：比較已提交版本 -> 選一份來源 -> 建立財務調整草稿 -> 調整收入 -> 編列人事與費用 -> 檢查損益 -> 匯出報表 -> 確認後提交。

## 閱讀與操作注意

1. 「提交」會鎖定編列，尚不代表主管已核准。
2. 年度比較現在比較的是兩年度預算；原專案尚未接入去年實績，不會把預算標成實績。全年住房率以全年總房晚／總可售房晚計算，差異以百分點呈現。
3. 各館與聯訂是兩套獨立預估，不直接相加；財務版本另存調整，沿用帶入時的房晚設定。
4. 報表列印目前選取的表，完整損益 PDF 請先勾選全部科目；Excel 永遠包含完整科目及 7 張工作表。
5. 年度比較不是另一份預算，不會另存或改動編列；請從底部切換館別與年度。

同目錄的 `annual-room-budget.drawio` 可直接用 diagrams.net 的「開啟現有圖表」或「檔案 -> 從裝置開啟」讀取，含「全站架構」及「角色操作流程」兩頁，所有方塊及連線可編輯。
